## 目录与页面规划（共 8 页）

### 第一部：认知奠基 —— 揭开本质，什么是 Serverless？

#### 01 · 揭开本质：什么是 Serverless（无服务器）？
* **核心金句**：**“Serverless 并不是真的没有服务器，而是让你【彻底摆脱买服务器和修服务器的苦差事】！”**
* **生活化比喻（自来水模型）**：
  * **买云服务器** ➔ 自己在后院挖井抽水：买水泵、修水管、防干涸，费钱又费力。
  * **Serverless 云服务** ➔ 直接接入自来水厂：拧开水龙头就有水，用多少水交多少钱，后台水厂 24 小时专业运维。
* **核心反差对比（传统云主机 vs Serverless）**：
  * **传统云主机**：买 2核4G 固定配置、包月扣费、半夜宕机要自己爬起来重启、必须自己装环境。
  * **Serverless 架构**：无虚拟电脑概念、有人访问瞬间唤醒、无人访问零待机成本、腾讯云团队 24 小时全托管。

### 第二部：场景切入 —— 什么时候你需要「云服务」？

#### 02 · 场景判别：你的应用需要云服务吗？
* **核心本质**：区分「纯前端静态展示」与「动态全栈持久化」。
* **免云服务场景（纯前端静态）**：
  * 个人作品集主页、活动宣传海报、单机计算器、本地剪贴板工具。
  * 特点：代码全在本地浏览器运行，刷新就重置，无需记住用户状态。
* **必须上云场景（全栈动态持久化）**：
  * 💬 **存留言/发帖**：多人社交互动，数据必须安全存放在服务端。
  * 🎮 **存用户进度**：游戏通关存档、用户个人偏好，换手机换电脑仍能找回。
  * 🤖 **接 AI 智能**：调用大模型 API，需服务端安全代理。
* **痛点反差**：
  * **传统做法**：买云主机 + 装 MySQL + 写后端路由 + 买域名配证书（耗时数天）。
  * **WorkBuddy**：AI 全自动打通全栈后端，点击确认一次，秒级全包！

### 第三部：全局视野 —— WorkBuddy 云服务五大能力全景

#### 03 · 全景大图：后端能力一站式全托管
* **底层基石**：深度集成腾讯云 CloudBase（企业级 Serverless 底座，稳定高可用）。
* **五大能力生活化全景隐喻**：
  1. 🗄️ **数据库 ➔ 「电子记账本」**：结构化业务数据存储，AI 自动建表直读直写。
  2. 📁 **文件存储 ➔ 「海量大仓库」**：图片、视频、附件等非结构化资产托管 (COS)。
  3. 🔐 **身份认证 ➔ 「专属门禁卡」**：开箱即用的多用户注册、登录与会话隔离。
  4. 📊 **数据统计 ➔ 「驾驶舱仪表盘」**：免埋点实时监控访问量与数据变化。
  5. 🧠 **内置大模型 ➔ 「外脑智囊顾问」**：免买 Key，一键为应用接入 AI 智商。

### 第四部：能力拆解 —— 五大核心能力详解（讲透用好）

#### 04 · 能力 ① · 数据库（Database）：应用结构化数据中枢
* **生活化认知**：**「应用的电子记账本」**。
* **核心特性**：
  * **按应用严格隔离**：独立数据环境，互不干扰。
  * **AI 自动建表**：用自然语言提业务需求，WorkBuddy 自动设计表字段与读写代码。
  * **可视化控制台**：直观查看表格、增删改查行记录。
* **避坑黄金准则（敲黑板）**：
  * 数据库只存**“文字、时间、数字和文件网址”**，绝不把几十兆的高清图片本体直接塞进数据库！

#### 05 · 能力 ② · 文件存储（Storage）：海量多媒体资产托管
* **生活化认知**：**「海量多媒体大仓库」**。
* **底层技术**：腾讯云对象存储（COS）驱动，大厂 CDN 加速，免配复杂桶名与秘钥。
* **最佳实践架构（三步协作链路）**：
  1. **Step 1**：用户在前端上传照片/文件至对象存储。
  2. **Step 2**：对象存储生成轻量 CDN 访问链接 (URL)。
  3. **Step 3**：数据库只记录该 URL 字符串（极速且轻量）。
* **避坑对比**：
  * ❌ 错误做法：大图转 Base64 塞数据库 ➔ 数据库膨胀卡死。
  * ✅ 正确做法：大图进文件存储，数据库只存网址 ➔ 查询极速流畅。

#### 06 · 能力 ③ · 身份认证（Authentication）：多用户与安全隔离
* **生活化认知**：**「专属门禁卡与储物柜钥匙」**。
* **分水岭**：让应用从“单机玩具”迈向“真正商业级多人应用”。
* **通俗化痛点对比（告别技术黑话）**：
  * ❌ **传统手写鉴权**：新手极易存明文密码泄漏；修改 URL 参数就能偷看别人的私密日记；刷新一下网页登录态就丢了。
  * ✅ **WorkBuddy 内置方案**：原生提供注册登录界面；自动绑定用户身份；天然数据权限隔离（张三绝对看不到李四的私密数据）。

#### 07 · 能力 ④ · 数据统计（Analytics）：业务与运行指标看板
* **生活化认知**：**「产品运营的驾驶舱仪表盘」**。
* **核心价值**：告别应用上线的“黑盒状态”，用数据指导产品迭代。
* **三大核心看板**：
  1. 📈 **流量热度**：PV（页面浏览总数） vs UV（独立访客人数）、活跃高峰时段。
  2. 💾 **容量监控**：数据库记录条数、图片文件消耗容量。
  3. ⚡ **服务健康**：接口调用量、报错率、AI 大模型调用消耗。

#### 08 · 能力 ⑤ · 内置大模型（Built-in LLM）：零门槛调 AI
* **生活化认知**：**「随叫随到的外脑智囊顾问」**。
* **彻底打破三大门槛**：
  * ❌ **无需自购 Key**：告别信用卡绑定、繁琐充值与 API Key 申请。
  * 🛡️ **后端安全代理**：Key 绝不暴露在前端代码中，杜绝爬虫盗刷高额账单。
  * ⚡ **开箱即用**：自然语言直接驱动 AI 完成文本总结、智能对话与内容打标。
* **三大典型落地场景**：
  * 智能对话助手（客服、陪伴）
  * 文本提炼与总结（文章速读、笔记整理）
  * 智能打标与语义搜索（照片内容分析）
